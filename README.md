# Projeto-Folha
# 💼 Sistema de Cadastro de Funcionários (PHP + MySQL)

Projeto desenvolvido para prática de CRUD (Create, Read, Update, Delete) utilizando **PHP, MySQL e HTML/CSS**.  
O sistema calcula **salário bruto, desconto de INSS e salário líquido** automaticamente.

---

## 🚀 Funcionalidades

- Cadastro de funcionários  
- Edição e exclusão de registros  
- Cálculo automático de:
  - Salário bruto (com base em salários mínimos)
  - Desconto de INSS
  - Salário líquido  
- Filtro de pesquisa por nome  
- Tabela dinâmica com listagem dos funcionários  

---

## 🛠️ Tecnologias Utilizadas

- **PHP** (PDO para conexão segura com MySQL)
- **MySQL** (phpMyAdmin)
- **HTML5 / CSS3**
- **Servidor Local:** XAMPP ou USBWebServer
